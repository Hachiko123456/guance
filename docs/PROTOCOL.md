# 实时协议说明（当前验证版本）

## 连接

当前验证到的对局逻辑 WebSocket 主机：

```text
hlxyxws.huanle.qq.com
```

大厅连接和微信小游戏长连接不要直接当作对局动作来源；采集 addon 只转发服务端二进制 frame，状态层只接受目标游戏连接。

## 外层聚合

实时消息使用动态长度聚合。解析器不写死偏移：先验证外层长度、`ff fd` 标记、聚合数量和每个子记录声明长度，再查找唯一合法聚合位置。

子记录当前验证：

```text
type = 15815
version = 2
```

## 命令候选

| 命令 | 意义 | 处理 |
|---:|---|---|
| 3001 | 发牌/开局状态 | 初始化本人的 27 张牌和级牌 |
| 3004 | 首出/开始 | 设置当前行动者 |
| 3005 | 出牌 | 扣除实际确认牌，校验牌型候选和余牌数 |
| 3006 | 过牌/轮转 | 不携带牌，推进牌权状态 |
| 3008 | 结算 | 只做最终离线一致性检查，不写入实时观察 |
| 3000/3002/3003/3009/3010/3011/3019 | 信息/房间/状态 | 已知安全信息；3010 在活跃局中按重连/快照处理并暂停 |

未知命令、聚合歧义、版本变化、重复动作和顺序倒退全部 fail-closed。

## 牌码

```text
code = (copy_index << 8) | (suit_code << 4) | rank_code
suit: 1=黑桃, 2=红桃, 3=梅花, 4=方块
rank: 1=A, 2..10=数字, 11=J, 12=Q, 13=K, 14=小王, 15=大王
copy_index: 0/1
```
