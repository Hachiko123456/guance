# 掼策 UI 与功能验收矩阵

版本：0.1.0
日期：2026-09-28

## 交付门槛

- 所有自动化验收项必须通过；
- 任何按钮没有可验证行为、信号没有消费者、或点击后无状态变化，都视为不通过；
- Windows 证书/代理/真实微信连接属于实机验收，不能以 offscreen 测试冒充；
- 任何真实环境失败必须在诊断页显示可操作的中文提示；
- 不允许留下 Guance/mitmdump 子进程或未恢复的代理设置。

## UI 按钮验收

| ID | 区域 | 控件/动作 | 验收结果 |
|---|---|---|---|
| UI-001 | 助手 | 开始使用 | 打开授权流程或进入已授权启动流程；状态不再停留在无变化的“尚未连接” |
| UI-002 | 授权 | 未勾选授权 | 同意按钮禁用；取消不改配置、不发授权信号 |
| UI-003 | 授权 | 勾选并同意 | 发出明确 consent=True；状态进入准备；错误时回到可操作状态 |
| UI-004 | 助手 | 停止并恢复网络 | 发出 stop；推荐清空；状态变为已停止 |
| UI-005 | 助手 | 先看看界面 | 进入明确标记的离线演示，不启动采集、不改网络、不加载真实模型 |
| UI-006 | 演示 | 退出演示 | 清除演示牌局、推荐和状态 |
| UI-007 | 助手 | 打开小窗 | 创建并显示唯一浮动窗口；重复点击不创建重复窗口 |
| UI-008 | 小窗 | 关闭按钮/窗口关闭 | 隐藏浮窗并同步 floatingVisible=False |
| UI-009 | 助手 | 查看其他候选 | 候选区域展开/收起，推荐数据不改变 |
| UI-010 | 设置 | 导入模型 | 打开文件选择；选择 npz 后发出路径；取消不改变模型 |
| UI-011 | 设置 | 移除本机授权 | 必须二次确认；取消不执行；确认发出 consent=True |
| UI-012 | 设置 | 修复网络 | 发出 repair；显示修复结果 |
| UI-013 | 诊断 | 导出诊断 | 生成脱敏诊断包，不包含 Cookie、Token、私钥、原始抓包或模型权重 |
| UI-014 | 顶部导航 | 助手/设置/诊断 | 页面切换正确，当前页状态稳定 |

## 实机验收（必须用户电脑执行）

1. 当前 Windows 11 + Clash：首次授权、启动采集、打开小游戏、进入对局。
2. 当前 Windows 11 + 无显式代理：direct 模式。
3. Windows 10 x64：启动、授权、停止、恢复代理。
4. 真实大掼蛋：至少前 20 个动作，推荐与离线回放一致。
5. 故意关闭/重启助手：无残留代理接管、无残留 Guance/mitmdump 进程。

## 交付判定

只有 UI-001～UI-014、CORE-001～CORE-010 的自动化或明确实机证据齐全，才标记“验收通过”。否则标记“开发版，未完全验收”，不得宣称生产可用。
