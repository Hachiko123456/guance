# 安全与隐私

## 授权

实时采集只用于用户明确授权的本机环境。未同意时：

- 不安装或删除证书；
- 不切换系统代理；
- 不启动真实采集；
- 取消和关闭弹窗必须是 no-op。

## 代理恢复

启动前记录当前用户代理状态。只有 helper ready 后才切换；停止和异常退出必须先恢复原代理，再关闭 helper。若检测到第三方在运行中修改代理，应停止接管并提示冲突。

## 数据最小化

实时 observation 只包含本人手牌和公开动作。结算中的对手手牌只能短暂用于离线一致性检查，不进入实时模型、ViewModel、诊断日志或导出包。

禁止记录或提交：

- Cookie、Authorization、token、账号标识；
- CA 私钥、证书私密材料；
- 原始二进制 payload 和完整抓包；
- 模型权重；
- 未脱敏的个人日志和本地配置。

## 解析与重放边界

保存抓包读取器是离线 reader，只筛选本地文件中的服务器 WebSocket frame。项目不添加请求重放、流量修改、自动点击或自动出牌能力。

## 模型

模型只在本机加载。生产模式要求模型加载成功，不静默切换规则策略。模型指纹可以出现在脱敏诊断中，但权重本身不能进入诊断包或 Git。

## 发布前检查

```powershell
git diff --cached --name-only
git diff --cached --binary | rg -n "Cookie|Authorization|PRIVATE KEY|\.mitm|best\.npz"
```

发布前还应执行打包目录清单、诊断导出和 Windows 代理恢复检查。具体门槛见 [ACCEPTANCE_STANDARD.md](ACCEPTANCE_STANDARD.md)。

## 版本与导出审查

以上是产品安全约束，不是基线所有异常路径都已通过实机测试的声明。持久运行租约、启动恢复和退出清理接线仍有待合并实现；请参阅 [架构版本表](ARCHITECTURE.md)。

本地开发版可以有原始调试录制开关，原始录制与脱敏诊断不是同一种资产。不能把“写在本地”理解为“可以分享”；发布和支持材料必须排除原始录制目录，真实录制只能在另行明确授权的环境进行。

上面的搜索用于找出需人工审查的命中；文档中的敏感字段名称可能正常命中，不能把字符串匹配当作秘密扫描的全部证明，也不能因为没有命中就保证安全。`.gitignore` 不会移除已经进入 Git 历史的内容；发现已提交秘密时应停止推送并另行处理，不擅自重写历史。
