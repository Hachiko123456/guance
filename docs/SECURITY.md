# 安全与隐私

## 网络授权

实时协议读取需要本机调试证书。掼策必须在用户明确勾选同意后，才可以尝试写入当前用户受信任根证书库。拒绝授权时不修改证书或代理。

## 代理恢复

启动前保存当前用户代理状态；只有采集器 ready 后才切换；停止时先恢复原状态。若代理在运行中被第三方修改，掼策停止接管并报告冲突。

## 数据最小化

实时观察只包含本人手牌和此前公开动作。历史结算中的对手手牌只可用于离线验证，永远不会进入实时模型输入或诊断包。

## 本地模型

模型权重只在本机加载；默认不上传。Git 仓库不提交用户训练权重。

## 第三方代码

FableDan vendored runtime 的许可证和 revision 保存在 `src/guance/infrastructure/model/fabledan_vendor/`。发布前需要完成许可证审查。
