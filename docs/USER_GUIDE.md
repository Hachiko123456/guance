# 用户使用说明

## 首次使用

1. 启动 `Guance.exe`。
2. 点击“开始使用”。
3. 按向导说明确认本机网络组件授权。证书只写入当前 Windows 用户；不需要手动打开命令行。
4. 打开微信和“大掼蛋”。
5. 进入支持的经典玩法对局。
6. 掼策只显示建议；实际出牌由用户在游戏内完成。

## 日常使用

以后启动掼策会自动检查本机组件、模型和网络环境。进入新对局后，状态同步成功且轮到本人时，助手页显示建议。

## 停止

点击“停止并恢复网络”。掼策先恢复原代理设置，再停止采集器。证书默认保留以避免重复授权；可以在设置中单独移除。

## 状态提示

- **等待对局**：采集器正常，尚未获得完整新局。
- **对局已同步**：牌局状态可信。
- **正在计算**：模型正在计算当前建议。
- **需要处理**：状态不完整、模型异常或网络组件需要修复；请打开诊断。

## 不支持的情况

- 不支持自动点击或自动出牌。
- 不支持未经用户授权的证书导入。
- 不保证 PAC、纯 SOCKS、TUN/VPN、企业认证代理环境。
- 规则变化或未知协议命令会暂停推荐，而不是猜测。
